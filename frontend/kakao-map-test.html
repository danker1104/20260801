⚙️ 설정 가이드

카카오 API 키 설정 방법:

1. frontend/js/config.js 파일을 열어주세요

2. KAKAO_MAPS_API_KEY 변수에 발급받은 키를 설정하세요:
const KAKAO_MAPS_API_KEY = 'YOUR_API_KEY_HERE';
3. .env 파일에도 동일한 키를 설정하세요:
KAKAO_MAPS_API_KEY=YOUR_API_KEY_HERE

키 발급: https://developers.kakao.com
도메인 등록: http://localhost:3000 (이미 등록됨)
