# SG-Food 문서 인덱스

SG-Food는 낯선 지역에서 빠르게 식당을 찾도록 돕는 위치 기반 맛집 추천 웹 앱입니다.

핵심 변경사항:
- 앱 이름: SG-Food
- 핵심 UX: 앱 진입 즉시 지도가 먼저 보이는 구조
- 디자인: Glassmorphism 스타일 적용

문서 목록:
- IDEA.md: 서비스 기획 초안
- PRD.md: 제품 요구사항
- TRD.md: 기술 아키텍처 + UI/UX 아키텍처 + 디자인 스펙 (단일 기준)
- Agents.md: 문서 작업/정합성 운영 가이드
- 아키텍처.md: TRD 통합 안내 문서 (참고용)
